## 📖 Overview

This project applies Big Data Analytics and Machine Learning techniques to predict hotel booking cancellations using the Hotel Booking Demand Dataset.

The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, predictive modeling, and model evaluation using PySpark.

This project was completed as part of the Big Data course at Princess Nourah bint Abdulrahman University.

---

## 🎯 Objectives

- Analyze hotel booking behavior
- Identify factors influencing booking cancellations
- Build predictive machine learning models
- Compare model performance
- Demonstrate the use of Big Data technologies for scalable analytics

---

## 📊 Dataset

Dataset: Hotel Booking Demand Dataset

- Source: Kaggle
- Records: 119,390
- Features: 31

Dataset:
https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

The dataset contains booking information for both Resort Hotels and City Hotels from July 2015 to August 2017.

## 🏆 Results

| Model | Accuracy | F1-Score |
|-------|---------:|---------:|
| Logistic Regression | 0.7381 | 0.6731 |
| Decision Tree | **0.7609** | **0.7351** |
| Random Forest | 0.7487 | 0.6776 |

The Decision Tree model achieved the best overall performance.
